# Rock Paper Scissors Game

## VEDA TECHNOLOGY – TASK 24

### Project Description
A Rock Paper Scissors game developed using HTML, CSS and JavaScript.
The user plays against the computer and the scoreboard tracks the results.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Features
- Three choice buttons
- Random computer choice
- Win, Lose and Draw logic
- Running score display
- Reset score functionality
- Responsive design

### Game Rules
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Same choices result in a Draw.

### How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Start playing!
